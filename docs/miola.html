PILLAR 2: CORE PLATFORM

The Brain & Data Hub

AI Microservices on AKS

Hosts all our proprietary AI logic as scalable containers.

Why AKS: Provides robust, scalable, and manageable orchestration for all our containerized backend services.
Headless OpenMRS on AKS

The stable, secure System of Record (SOR) for all clinical data.

Why OpenMRS: Leverages a mature, standardized clinical data model, saving years of development effort on commodity EHR features.
Azure Event Hubs

The event-driven backbone of the platform.

Why Event-Driven: Decouples services for resilience and scalability. OpenMRS just fires an event; it doesn't need to know who is listening.
Azure OpenAI Service

Provides secure, enterprise-grade access to powerful LLMs.

Why Managed AI: Ensures data privacy, compliance (HIPAA), and scalability for all our intelligent features without managing infrastructure.

PILLAR 3: CENTRAL DATA PLATFORM

The Monetization Engine

Secure Ingestion

API Management ➡ Event Hubs

Why: Provides a secure, scalable, and throttled entry point for the high-volume FHIR data stream from the Core Platform.
De-identification Engine

Azure Functions / Databricks job that scrubs all PHI.

Why: A critical compliance step. This ensures our data asset is fully anonymized and safe for analytics and commercialization.
Analytics & Storage Lakehouse

Azure Blob Storage (Raw) + Azure Databricks (Processed).

Why Lakehouse: Combines cost-effective storage (Blob) with powerful, large-scale data processing (Databricks) for analytics.
Customer Access Layer

Portal, Metered APIs, and Sandboxes for partners.

Why: The products we sell. Provides multiple, secure ways for customers to interact with and derive value from our unique data asset.
